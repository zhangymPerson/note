# 设计方向确认 · 纸墨 + 分类彩色

日期：2026-11-23

## 决策

三份纸墨家族初稿（`design-demos/A-纯纸墨.html`、`B-纸墨秩序.html`、`C-纸墨分类彩色.html`）摆出后，用户选定：

> **C · 纸墨分类彩色**

原话（选项）：「C · 纸墨分类彩色 —— 纸墨底 + 分类彩色圆点与陶土热力，彩色只干分类一件事。」

## 方向要点（实现时照此执行）

- 同一本纸与墨：衬线只给署名位（品牌/页标题/日期/笔记标题），正文黑体，时间等宽 tabular-nums，卡片纸面 + 极浅阴影、8px 圆角，虚线页线/账簿，骨架屏、空态 SVG 线条。
- 三主题共用品牌墨绿家族：亮 = 微暖纸白，暗 = 暖黑深墨纸，护眼 = 米绿纸。
- **彩色只干「分类」一件事**：6 色固定色板（装饰圆点），分类树/列表行/详情/速记卡/账簿都有那颗色点；热力图换陶土暖阶。
- 明确不做：渐变（品牌徽标 conic 渐变除外，可保留或改纯色）、emoji、纸纹噪点贴图。
- 正文 ≥14px、三主题可读性不降、`{@html}` 净化与安全不变量不动（DOMPurify → highlightRendered 链不变）。
- 兼容性注记：原型里的 `color-mix` 只用于顶栏毛玻璃（方向 B 有、C 未用）；C 用 CSS 变量承载分类色，随主题切换换值。
